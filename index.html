01 / APLICACIÓN DE SOFTWARE

MechSync↗

Aplicación para la operación administrativa y técnica de servicios automotrices. Organiza clientes, vehículos y órdenes de trabajo mediante un frontend web, una API REST y una base de datos relacional.

El código incluye autenticación con JWT y acceso por roles. Sus componentes se mantienen en tres repositorios independientes.

  • React
  • Vite
  • Java 17
  • Spring Boot
  • MySQL
